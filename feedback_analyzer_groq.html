Аналізатор відгуків студентів

Локальний застосунок — жодні дані нікуди не завантажуються, крім прямого запиту до Groq API з вашого браузера.

1Groq API ключ

Немає ключа? Отримайте безкоштовно за 1 хвилину на console.groq.com/keys (реєстрація поштою, без картки). Ключ використовується лише у вашому браузері й нікуди не зберігається.

2Файл з відгуками

Натисніть, щоб обрати файл або перетягніть сюди CSV

3Які колонки аналізувати

4NPS, спікери та загальні оцінки (опційно — можна лишити порожнім)

Якщо оберете — застосунок сам порахує NPS за стандартною формулою (% Promoters − % Detractors).

Тільки колонки, де оцінювали конкретну людину поіменно — кожна стане окремим рядком.

Оберіть колонки з узагальненими оцінками (не по конкретних людях) — для кожної порахується проста середня і покажеться окремим блоком у звіті.
